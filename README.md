# Fieldcraft: Pine Valley

A full-screen first-person voxel-world game with deterministic seeded terrain, trees, biome foliage, and destructible blocks.

## Run

Install Node.js 20.19+ or 22.12+, then from this folder run:

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite. To make a production build, run `npm run build`.

## Play

- Desktop: enter a custom seed on the title screen or randomize one, then click **Enter world**. Use `W A S D` to move, mouse to look, `Space` to jump, `Shift` to sprint, and hold left mouse over a block to break it. Press `Esc` to pause and `R` for a new world.
- Touch: use the left pad to move, drag the right side to look, and tap the on-screen jump, break, sprint, and pause controls.
